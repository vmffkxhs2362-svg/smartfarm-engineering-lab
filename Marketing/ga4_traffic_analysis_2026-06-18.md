## 🛠️ 5. 행동 이벤트 진단 및 오류 개선 (Event Diagnostic)

GA4 API 로그 분석 결과, 사용자의 구체적인 상호작용 행동 패턴에서 개선할 부분이 식별되었습니다.

### ❌ 탭 전환(tab_switch) 세부 매개변수 누락 오류
*   **현상**: `calculator_tab_switch` 이벤트는 **43회 (6명)** 정상 수집되었으나, API 쿼리 결과 `customEvent:tab_name` 매개변수 호출 시 `400 Bad Request` 에러가 발생합니다.
*   **원인**: 소스코드([index.html](file:///g:/My%20Drive/Antigravity/Headquater/Career/Passive_Income_Hub/index.html#L3226-L3230)) 상에서는 `tab_name` 매개변수를 전송하고 있으나, **GA4 웹 콘솔 설정(Admin > Custom Definitions > Create Custom Dimensions)에서 `tab_name`을 맞춤 측정기준(Event-scoped Custom Dimension)으로 수동 등록하지 않아** API가 이 값을 식별하지 못하는 상태입니다.
*   **조치 사항**: GA4 관리자 페이지에서 `tab_name` 측정기준을 등록해 주시면, 향후 VPD / 양액 / 밸브 탭 중 어떤 탭이 가장 높은 비중을 차지하는지 상세히 추적할 수 있습니다.

### 📉 피드백 클릭율 (Conversion Rate) 0%
*   현재 피드백 링크 클릭(`feedback_link_click`)은 누적 **0건**입니다.
*   **조치 사항**: 계산 결과 패널 하단에 **"피드백 남기고 개선점 건의하기"** 버튼을 추가하고, 플로팅 피드백 버튼(FAB)의 시각적 피드백 효과(Pulse 애니메이션)를 추가하여 순수 의견 수집 행동 유도(CTA)를 보완해야 합니다. (※ 노션 템플릿/엑셀 등 유료 제품 홍보 배너는 상품이 완전히 준비될 때까지 사용자 혼란을 방지하기 위해 노출을 전면 유보합니다.)
